Title: User Login

As a registered user,
I want to log in to the application using my email address and password,
So that I can securely access my account.

Acceptance Criteria:

1. The user should be able to enter a registered email address.
2. The user should be able to enter a password.
3. Clicking the Login button with valid credentials should successfully log in the user.
4. An appropriate error message should appear for an incorrect password.
5. An appropriate validation message should appear if the email or password is empty.
6. The password should be displayed in masked format.
